# Changelog

## 1.0.0 — 2026-10-26
- First public release under the FreeMagento namespace (previously `Mentalworkz_CustomerTwoFactor`).
- Email one-time-code 2FA for storefront customer login, optional or required mode.
- Trusted devices ("remember this device"), revocable from My Account › Login Security.
- HMAC-hashed codes, expiry, attempt limits, resend cooldown, daily cleanup cron.
- Hyvä-native templates (Alpine.js + Tailwind).
